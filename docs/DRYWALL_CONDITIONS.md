# Vanguard Takeoff — default drywall conditions

New projects start with these conditions (source: `web/src/lib/drywallDefaults.js`).
Rename each tag to match your drawings, set wall heights, and replace the
starter rates with Vanguard's own production numbers.

**How to read a rate:** "1 sheet / 21.82 SF" means one 4×12 sheet for every
21.82 SF of measured wall (one face). Wall SF is one face; wall LF is the
traced length. Board rates include 10% waste; the condition's waste % only
adjusts the SF/LF columns in the report.

**Layers and Stud O.C.:** set them on the condition (top bar). Lines marked
"Layers" (board, screws) and "Stud O.C." (studs, channel, grid cross tees)
are re-figured automatically; the rates below are at the default setting.
